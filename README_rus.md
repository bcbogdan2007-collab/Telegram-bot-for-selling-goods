# 🛍️ Telegram-бот для продажи товаров (на примере магазина одежды)

Демонстрационный проект с набором готовых функций: **Telegram-бот для продажи товаров**, собранный на примере **интернет-магазина одежды**. Включает каталог, корзину, промокоды, оформление заказа и историю покупок — всё на **Inline-клавиатурах** с хранением данных в локальной базе **SQLite**.

Пользователь листает каталог, выбирает размер, добавляет товары в корзину, применяет промокод, вводит телефон и адрес и подтверждает заказ. Администратор мгновенно получает уведомление.

## Возможности

- **Каталог с категориями и постраничной навигацией:** интерактивный просмотр товаров по категориям;
- **Карточки товаров с фото:** изображение из ссылки, из локальной папки `images/` или по `file_id` Telegram;
- **Выбор размера:** выбранный размер подсвечивается ✅ перед добавлением в корзину;
- **Управление корзиной:** увеличение/уменьшение количества, удаление позиций, полная очистка;
- **Промокоды:** процентные и фиксированные скидки с минимальной суммой заказа и лимитом использований, один промокод на пользователя;
- **Пошаговое оформление заказа:** сбор номера телефона (кнопкой «Отправить контакт» или текстом) и адреса доставки;
- **Экран подтверждения заказа:** проверка позиций, суммы, скидки и итога перед отправкой;
- **Раздел «Мои заказы»:** последние 10 заказов пользователя с датой, суммой и статусом;
- **Уведомления администратору:** мгновенное сообщение в Telegram на `ADMIN_ID` о каждом новом заказе;
- **Админ-команды:** `/products` (список ID товаров), `/setphoto` (прикрепить фото к товару), `/addpromo` (создать промокод);
- **Надёжная обработка ввода:** нормализация номера телефона, проверка длины адреса, понятные сообщения об ошибках.

## Конфиденциальность

- хранятся только данные, необходимые для заказов: **Telegram ID пользователя, имя, телефон, адрес, содержимое корзины и история заказов**;
- текст сообщений **не логируется** (логи содержат только служебную информацию);
- все данные хранятся в **локальной базе SQLite** (`shop.db`) и не передаются третьим лицам.

Установка и запуск

1. Получите токен Telegram-бота: напишите @BotFather, отправьте команду /newbot.
2. Узнайте свой Telegram ID (для уведомлений и админ-команд): напишите @userinfobot.
3. Установите зависимости (рекомендуется виртуальное окружение):
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. Создайте файл .env на основе примера и впишите данные:
   ```bash
   cp .env.example .env            # Windows: copy .env.example .env
   ```
   ```env
   BOT_TOKEN=ваш_токен_бота
   ADMIN_ID=ваш_telegram_id
   ```
5. (Опционально) добавьте фото товаров в папку images/ под именами из catalog.py.
6. Запустите бота:
   ```bash
   python main.py
   ```
7. Откройте бота в Telegram, отправьте /start и перейдите в каталог.

Стартовые промокоды PROMOS в config.py Создаются при первом запуске (код, тип, значение, мин. сумма, лимит)

База данных

При первом запуске бот автоматически создаёт shop.db со следующими таблицами:

· categories, products — каталог, загруженный из catalog.py;
· cart — позиции по ключу (user_id, product_id, size);
· promos, user_promo — активные промокоды и код, применённый каждым пользователем;
· orders, order_items — оформленные заказы и их позиции.

Каталог и стартовые промокоды добавляются только один раз — когда соответствующие таблицы пусты.

Админ-команды

Команда Назначение
/products Показать ID товаров (и 📷, если установлено фото)
/setphoto НОМЕР Отправить как подпись к фото, чтобы прикрепить картинку к товару
/addpromo КОД percent\|fixed ЗНАЧЕНИЕ [МИН_СУММА] Создать или заменить промокод

Возможные проблемы

· «BOT_TOKEN пустой» / бот не запускается — убедитесь, что файл .env лежит рядом с main.py и содержит BOT_TOKEN.
· Администратор не получает уведомления — проверьте, что ADMIN_ID — это числовой Telegram ID (не @username).
· Фото товара не отображается — проверьте, что файл есть в папке images/, ссылка корректна или file_id принадлежит этому боту.
· Промокод отклонён — код может быть неактивен, исчерпан, уже использован этим пользователем или сумма заказа меньше минимальной.
· «message is not modified» — безобидная ошибка Telegram, уже обработана в коде.
· Ошибка базы данных — убедитесь, что у скрипта есть права на запись в папку проекта для создания/обновления shop.db.

Безопасность

Не публикуйте файл .env и базу shop.db. Добавьте .env, *.db и venv/ в .gitignore.
